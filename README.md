# 독자 데이터 랩 (Reading Data Lab)

네이버웹툰 『유체를 이탈하였습니다』(이슬 작가, 월요웹툰) 1~20화를 정주행하며 공개 화면의 지표와 인기 댓글을 직접 옮겨 적고, 회차마다 남긴 리딩 로그와 같은 회차 축에 겹쳐 본 개인 분석 페이지입니다.

- 홈 → 01 원본 데이터 / 02 독자 반응 분석 / 03 데이터 시각화
- 오른쪽 위 [데이터 차팅] / [인사이트] 토글: 인사이트 보기에서는 차트 위 표시와 메모 칸이 나타납니다.
- 메모는 보는 사람의 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다.

## 데이터 출처

| 항목 | 범위 | 출처 |
| --- | --- | --- |
| 회차별 평균 별점 | 1~20화 | 네이버웹툰 공개 화면, 2026.11.6 직접 옮겨 적음 |
| 회차별 좋아요 | 11~20화 | 네이버웹툰 공개 화면, 2026.11.6 |
| 인기 댓글 | 10~20화 인기 댓글 90개 | 앱 화면 직접 확인, 원문 요지만 싣고 닉네임은 싣지 않음 |
| 몰입(1~5)·다음 화 볼 이유·남은 질문 | 1~20화 | 본인 리딩 로그 |

자동 수집(크롤링)은 쓰지 않았습니다. 미리보기 21~25화는 제외했습니다.

## 한계

- 인기 댓글만 봤습니다. 전체 댓글의 분포와 다를 수 있습니다.
- 찐팬 배지는 독자가 숨길 수 있어, "배지가 보이지 않는 댓글"이 곧 신규 독자를 뜻하지는 않습니다.
- 리딩 로그는 1인 기록이라 가설을 세우는 데만 쓰고, 판단은 독자 데이터로 했습니다.
- 좋아요는 최근 회차일수록 쌓인 기간이 짧아 회차 간 단순 비교에 주의가 필요합니다.

## 로컬에서 보기

빌드 과정이 없는 단일 HTML 파일입니다.

1. `index.html`을 더블클릭해 브라우저로 엽니다.
2. 또는 이 폴더에서 간단한 서버를 띄웁니다(선택): `python -m http.server 8000` 후 `http://localhost:8000` 접속.

외부 의존성은 글꼴(Pretendard, jsDelivr CDN) 하나입니다. 인터넷이 없으면 시스템 글꼴로 대체되어 보입니다.

## 폴더 구조(아카이브 확장 계획)

이 저장소의 루트를 개인 콘텐츠 분석 아카이브로 쓰고, 이 페이지를 첫 프로젝트로 둡니다. 지금은 루트의 `index.html`이 독자 데이터 랩이고, 프로젝트가 늘어나면 아래 구조로 옮깁니다.

```
/                     아카이브 목록(프로젝트 카드 몇 개만 있는 정적 index.html, 추후)
/reading-data-lab/    독자 데이터 랩(이 페이지)
/<다음-작품-또는-주제>/  다음 분석
```
