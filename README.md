# Data Archive Lab

좋은 작품을 알아보는 안목을 기르기 위해, 읽은 작품마다 판단의 근거를 남기는 개인 웹툰 리딩 로그입니다.
읽고, 기록하고, 판단하고, 제안합니다. 네이버웹툰 공식 시스템이 아닙니다.

주소: https://reading-archive-ten.vercel.app/lab/

## 구성

| 탭 | 내용 |
| --- | --- |
| 개요 | 검토 목적, 검토 현황(회차 로그, 내 별점 평균, 열린 질문, 풀린 질문), 작품 정보, 초기 판단 |
| 회차 로그 | 최신 회차부터. 좋았던 점, 아쉬운 점, 새로 생긴 질문, 풀린 질문, 내 별점(몰입), 다음 화 볼 이유, 공개 반응, 작가 의도 |
| 데이터 차팅 | 내 별점, 공개 평균 별점, 댓글 수, 다음 화 볼 이유를 같은 회차 축에 줄을 나눠 표시. 핵심 회차(12화, 15화) 표시 |
| 검토 메모 | 작품 검토 기준 4가지(관찰한 사실, 나의 해석, 검토 판단, 추가로 확인할 질문), 매력, 작가 의도, 최종 검토 메모, 작가님께 드릴 제안, 질문 장부, 이 기록의 한계 |

CASE 01: [유체를 이탈하였습니다] 1~20화 (2026.11.6 수집)

## 데이터와 한계

- 좋아요와 댓글 수는 11~20화만 수집했습니다.
- 공개 별점 20개는 수집 당시 옮겨 적은 값이며, 별점 화면 캡처는 없습니다.
- 내 별점(몰입), 다음 화 볼 이유, 질문은 1인 기록입니다.
- 인용한 댓글은 닉네임 없이 원문 요지와 공감 수만 남겼습니다.
- 원본 캡처 대조 기록: [VERIFICATION.md](VERIFICATION.md)

방문 기록은 시간, 대략적 지역, 기기, 처음 연 화면, 들어온 곳만 남기고 이름과 IP는 저장하지 않습니다.
